Site de Formula 1

Projeto desenvolvido em HTML puro para uma atividade academica de Front-End.

Sobre o projeto

O site apresenta informacoes sobre a Formula 1, com paginas dedicadas a pilotos, circuitos e carros marcantes da categoria.

Paginas

* Inicio
* Pilotos
* Circuitos
* Carros
* Formulario

Recursos utilizados

* HTML5
* Estrutura semantica
* Tabelas
* Formularios
* Imagens
* Audio local
* Tags de organizacao e informacao

 Organizacao

`html/` - paginas do site
`img/` - imagens utilizadas
`audio/` - arquivo de audio
`video/` - arquivos de video
`README.md` - informacoes sobre o projeto
